# Website STEM lớp 4 – Vật dẫn nhiệt tốt, vật dẫn nhiệt kém

Mở `index.html` bằng trình duyệt hoặc triển khai toàn bộ thư mục lên GitHub Pages.

## Cấu trúc
- Thanh điều hướng: Trang chủ – Học tập – Ôn tập – Mở rộng.
- Học tập: Bài 1 – Vật dẫn nhiệt tốt, vật dẫn nhiệt kém.
- Bài 1 gồm Thử thách, Khám phá và Ý tưởng; các phần được mở tuần tự sau khi hoàn thành phần trước.
- Ôn tập và Mở rộng hiện là trang chờ để bổ sung nội dung sau.

Giữ tất cả tệp hình ảnh và video cùng cấp với `index.html` để website hiển thị đầy đủ.
